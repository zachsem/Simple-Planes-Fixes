# Contributing

Bug reports and compatibility reports are welcome.

## Before opening an issue
- Reproduce the problem with the newest release of Simple Planes Fixes.
- Confirm that Simple Planes 3.0.1.7 is installed.
- If an optional integration is involved, include that mod's exact version.
- Keep the original Simple Planes jar unmodified.

## Bug reports
Please attach `latest.log` or the relevant crash report and include clear reproduction steps. If the issue involves a specific aircraft, enable advanced tooltips with **F3 + H** and include its registry ID.

## Pull requests
Keep changes narrowly focused on restoring intended 1.12.2 functionality or improving compatibility. Avoid inventing replacement recipes for integrations whose required content is absent.

All contributed code must be compatible with the project's GPL-3.0 license.
